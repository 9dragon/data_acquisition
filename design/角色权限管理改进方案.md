# 角色权限管理改进方案

**问题分析**：
当前角色管理只支持分配权限，但缺少权限详情展示和权限生效验证。

---

## 一、当前功能状态

### 1.1 已实现功能 ✅
- 角色列表展示
- 角色CRUD操作
- 权限树展示
- 权限分配（多选）
- 系统预置角色保护

### 1.2 缺少功能 ❌
- 列表中不显示角色拥有的权限数量
- 无法查看角色的具体权限详情
- 无法验证权限是否真正生效
- 权限类型（菜单/按钮/API）区分不明显

---

#### 3. 数据结构
```typescript
// 添加权限数量字段
interface Role {
  id: number
  code: string
  name: string
  description?: string
  permissions?: string
  isSystem?: number
  permissionCount?: number  // 新增：权限数量
  userCount?: number
  createdAt: string
  updatedAt: string
}

// 当前查看的角色
const currentRole = ref<Role | null>(null)
const permissionViewDialogVisible = ref(false)
const rolePermissions = ref<Permission[]>([])
const activePermissionTab = ref('menu')

// 按类型分组权限
const permissionsByType = computed(() => {
  const menu: Permission[] = []
  const button: Permission[] = []
  const api: Permission[] = []

  rolePermissions.value.forEach(p => {
    if (p.type === 'menu') menu.push(p)
    else if (p.type === 'button') button.push(p)
    else if (p.type === 'api') api.push(p)
  })

  return { menu, button, api }
})
```

#### 2. 权限验证API
后端添加权限验证接口：

```java
@RestController
@RequestMapping("/roles")
public class RoleController {

    /**
     * 验证角色是否拥有指定权限
     */
    @PostMapping("/{id}/test-permission")
    public Result<Map<String, Boolean>> testPermission(
            @PathVariable Long id,
            @RequestBody List<String> permissionCodes
    ) {
        Map<String, Boolean> results = new HashMap<>();

        for (String code : permissionCodes) {
            try {
                // 检查角色是否拥有该权限
                boolean hasPermission = roleService.hasPermission(id, code);
                results.put(code, hasPermission);
            } catch (Exception e) {
                results.put(code, false);
            }
        }

        return Result.success(results);
    }
}
```

## 五、技术要点

### 5.1 后端扩展

**RoleService扩展**：
```java
public interface RoleService {
    // 获取角色权限数量
    Integer getPermissionCount(Long roleId);

    // 获取角色的完整权限详情
    List<Permission> getRolePermissionsDetail(Long roleId);

    // 检查角色是否拥有指定权限
    boolean hasPermission(Long roleId, String permissionCode);
}
```

**RoleController扩展**：
```java
/**
 * 获取角色权限详情
 */
@GetMapping("/{id}/permissions-detail")
public Result<List<Permission>> getRolePermissionsDetail(@PathVariable Long id) {
    List<Permission> permissions = roleService.getRolePermissionsDetail(id);
    return Result.success(permissions);
}

/**
 * 获取角色权限数量
 */
@GetMapping("/{id}/permission-count")
public Result<Integer> getPermissionCount(@PathVariable Long id) {
    Integer count = roleService.getPermissionCount(id);
    return Result.success(count);
}
```
