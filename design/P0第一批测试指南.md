## 一、环境准备

### 1.1 数据库初始化

**执行迁移脚本（按顺序）**:

```bash
# 进入迁移脚本目录
cd source/deployment/config/mysql/migrations

# 1. 权限表迁移
mysql -u root -p data_acquisition < 02_add_permission_tables.sql

# 2. 阶段表迁移
mysql -u root -p data_acquisition < 03_add_stage_tables.sql
```

**验证数据**:
```sql
-- 检查权限表
SELECT COUNT(*) FROM t_permission;
-- 预期结果: 约20条预置权限

-- 检查阶段表
SELECT COUNT(*) FROM t_stage;
-- 预期结果: 6条预置阶段

-- 检查超级管理员角色的权限
SELECT permissions FROM t_role WHERE code = 'ADMIN';
-- 应包含所有权限ID（逗号分隔）
```

### 1.2 启动后端服务

```bash
cd source/backend
mvn clean install
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

**验证后端启动**:
- 访问: http://localhost:8080
- Knife4j文档: http://localhost:8080/doc.html
- 检查日志无ERROR

### 1.3 启动前端服务

```bash
cd source/frontend
npm install
npm run dev
```

**验证前端启动**:
- 访问: http://localhost:3000
- 应显示登录页面
