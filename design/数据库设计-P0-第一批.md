## 设计概述

### 设计原则

1. **基于现有表扩展**：在 `init.sql` 基础上扩展，保持风格一致
2. **支持RBAC权限模型**：用户-角色-权限三级关联
3. **JSON字段存储复杂对象**：任务模板、资料需求等使用JSON
4. **软删除机制**：使用 `deleted` 字段标记删除状态
5. **审计字段**：统一使用 `createdBy`、`createdAt`、`updatedBy`、`updatedAt`

### 涉及模块

| 模块 | 主要表 | 说明 |
|------|--------|------|
| 登录认证 | t_user (扩展) | 添加登录时间、IP字段 |
| 角色权限 | t_permission, t_role_permission | 权限定义、角色权限关联 |
| 工序管理 | t_process (扩展) | 添加排序字段 |
| 项目阶段 | t_stage | 阶段定义、任务模板（JSON） |

```sql
ALTER TABLE t_user ADD COLUMN last_login_time DATETIME DEFAULT NULL COMMENT '最后登录时间';
```

**字段说明**：

| 字段名 | 类型 | 必填 | 索引 | 说明 |
|--------|------|------|------|------|
| last_login_time | DATETIME | 否 | Y | 最后登录时间，用于会话管理 |
| last_login_ip | VARCHAR(50) | 否 | N | 最后登录IP，用于安全审计 |

### 2. 权限表 (t_permission)

**说明**：存储系统所有权限，支持树形结构

```sql
CREATE TABLE t_permission (
    id VARCHAR(50) PRIMARY KEY COMMENT '权限ID',
    code VARCHAR(100) NOT NULL UNIQUE COMMENT '权限编码，如：project:create',
    name VARCHAR(100) NOT NULL COMMENT '权限名称',
    type ENUM('menu', 'button', 'api') NOT NULL DEFAULT 'button' COMMENT '权限类型',
    parent_id VARCHAR(50) DEFAULT NULL COMMENT '父权限ID',
    path VARCHAR(200) DEFAULT NULL COMMENT '前端路由路径',
    method VARCHAR(10) DEFAULT NULL COMMENT 'HTTP方法：GET/POST/PUT/DELETE',
    description VARCHAR(500) DEFAULT NULL COMMENT '权限描述',
    sort_order INT DEFAULT 0 COMMENT '排序序号',
    status TINYINT(1) DEFAULT 1 COMMENT '状态：1启用 0禁用',
    deleted TINYINT(1) DEFAULT 0 COMMENT '删除标记',
    created_by VARCHAR(50) DEFAULT NULL COMMENT '创建人',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_by VARCHAR(50) DEFAULT NULL COMMENT '更新人',
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_code (code),
    INDEX idx_parent_id (parent_id),
    INDEX idx_type (type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='权限表';
```

**字段说明**：

| 字段名 | 类型 | 必填 | 索引 | 说明 |
|--------|------|------|------|------|
| id | VARCHAR(50) | 是 | PK | 权限ID，使用UUID |
| code | VARCHAR(100) | 是 | UK | 权限编码，全局唯一，如 project:create |
| name | VARCHAR(100) | 是 | N | 权限名称，如"创建项目" |
| type | ENUM | 是 | Y | menu(菜单)、button(按钮)、api(接口) |
| parent_id | VARCHAR(50) | 否 | Y | 父权限ID，支持树形结构 |
| path | VARCHAR(200) | 否 | N | 前端路由路径，如 /project/list |
| method | VARCHAR(10) | 否 | N | HTTP方法，如 GET、POST |
| description | VARCHAR(500) | 否 | N | 权限描述 |
| sort_order | INT | 否 | N | 排序序号 |
| status | TINYINT(1) | 否 | N | 状态：1启用 0禁用 |

### 3. 角色权限关联表 (t_role_permission)

**说明**：多对多关联表，连接角色和权限

```sql
CREATE TABLE t_role_permission (
    id VARCHAR(50) PRIMARY KEY COMMENT '主键',
    role_id VARCHAR(50) NOT NULL COMMENT '角色ID',
    permission_id VARCHAR(50) NOT NULL COMMENT '权限ID',
    created_by VARCHAR(50) DEFAULT NULL COMMENT '创建人',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    UNIQUE KEY uk_role_permission (role_id, permission_id),
    INDEX idx_role_id (role_id),
    INDEX idx_permission_id (permission_id),
    FOREIGN KEY (role_id) REFERENCES t_role(id) ON DELETE CASCADE,
    FOREIGN KEY (permission_id) REFERENCES t_permission(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='角色权限关联表';
```

**字段说明**：

| 字段名 | 类型 | 必填 | 索引 | 说明 |
|--------|------|------|------|------|
| id | VARCHAR(50) | 是 | PK | 主键，使用UUID |
| role_id | VARCHAR(50) | 是 | UK, FK | 角色ID |
| permission_id | VARCHAR(50) | 是 | UK, FK | 权限ID |
| created_by | VARCHAR(50) | 否 | N | 创建人 |

**约束**：
- 联合唯一索引 (role_id, permission_id)
- 级联删除：删除角色或权限时自动删除关联记录

### 5. 项目阶段表 (t_stage)

**说明**：定义项目阶段，支持任务模板配置（JSON字段）

```sql
CREATE TABLE t_stage (
    id VARCHAR(50) PRIMARY KEY COMMENT '阶段ID',
    `key` VARCHAR(50) NOT NULL UNIQUE COMMENT '阶段唯一标识，如：preparation',
    name VARCHAR(100) NOT NULL COMMENT '阶段名称',
    description VARCHAR(500) DEFAULT NULL COMMENT '阶段描述',
    icon VARCHAR(50) DEFAULT NULL COMMENT '图标',
    color VARCHAR(20) DEFAULT NULL COMMENT '显示颜色',
    progress_mode ENUM('by_task', 'by_device') NOT NULL DEFAULT 'by_device' COMMENT '推进方式',
    is_system TINYINT(1) DEFAULT 0 COMMENT '是否系统预置',
    default_weight INT DEFAULT 0 COMMENT '默认权重 0-100',
    task_templates JSON DEFAULT NULL COMMENT '任务模板数组（JSON）',
    sort_order INT DEFAULT 0 COMMENT '排序序号',
    status TINYINT(1) DEFAULT 1 COMMENT '状态：1启用 0禁用',
    deleted TINYINT(1) DEFAULT 0 COMMENT '删除标记',
    created_by VARCHAR(50) DEFAULT NULL COMMENT '创建人',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_by VARCHAR(50) DEFAULT NULL COMMENT '更新人',
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_key (`key`),
    INDEX idx_sort_order (sort_order),
    INDEX idx_is_system (is_system)
```

## 索引设计

### 索引策略

1. **主键索引**：所有表的 `id` 字段
2. **唯一索引**：防止重复数据
   - `t_permission.code` - 权限编码唯一
   - `t_stage.key` - 阶段标识唯一
   - `t_role_permission.role_id + permission_id` - 联合唯一
3. **普通索引**：提升查询性能
   - `t_user.last_login_time` - 登录时间查询
   - `t_permission.parent_id` - 树形结构查询
   - `t_role_permission.role_id, permission_id` - 关联查询
   - `t_process.sort_order` - 排序查询
   - `t_stage.sort_order` - 排序查询
4. **状态索引**：筛选活跃数据
   - `t_permission.type` - 权限类型筛选
   - `t_stage.is_system` - 系统预置筛选

### 索引列表

| 表名 | 索引名 | 字段 | 类型 | 说明 |
|------|--------|------|------|------|
| t_user | idx_last_login | last_login_time | INDEX | 登录时间查询 |
| t_permission | idx_code | code | UNIQUE | 权限编码唯一 |
| t_permission | idx_parent_id | parent_id | INDEX | 父权限查询 |
| t_permission | idx_type | type | INDEX | 类型筛选 |
| t_role_permission | uk_role_permission | role_id, permission_id | UNIQUE | 联合唯一 |
| t_role_permission | idx_role_id | role_id | INDEX | 角色查询 |
| t_role_permission | idx_permission_id | permission_id | INDEX | 权限查询 |
| t_process | idx_sort_order | sort_order | INDEX | 排序查询 |
| t_stage | idx_key | key | UNIQUE | 阶段标识唯一 |
| t_stage | idx_sort_order | sort_order | INDEX | 排序查询 |
| t_stage | idx_is_system | is_system | INDEX | 系统预置筛选 |

## 表关系图

### ER图描述

```
t_user (用户表)
  │
  └──(1:N)── t_user_role ───(N:1)── t_role (角色表)
                                      │
                                      └──(1:N)── t_role_permission ───(N:1)── t_permission (权限表)
                                                                                    │
                                                                                    └──(1:N)── 自身 (parent_id)

t_project (项目表)
  │
  └──(1:N)── t_process (工序表) [已存在，添加sort_order]

t_stage (阶段表) [新增]
  │
  ├──(JSON)── task_templates (任务模板)
  │             │
  │             └──(JSON)── material_requirements (资料需求)
  │
  └──(1:N)── 自身 (不推荐，使用sort_order排序)
```

### 关系说明

1. **用户-角色-权限（RBAC）**
   - 用户 → 角色（多对多，通过 t_user_role）
   - 角色 → 权限（多对多，通过 t_role_permission）
   - 权限 → 权限（自关联，parent_id）

2. **项目-工序**
   - 项目 → 工序（一对多，通过 project_id）

3. **阶段-任务模板**
   - 阶段包含任务模板（一对多，JSON字段存储）
   - 任务模板包含资料需求（一对多，JSON字段存储）

## JSON字段结构

### task_templates (任务模板数组)

**位置**：`t_stage.task_templates`

**数据类型**：JSON Array

**结构定义**：

```json
[
  {
    "id": "uuid",
    "key": "task_key",
    "name": "任务名称",
    "description": "任务描述",
    "defaultWeight": 10,
    "materialRequirements": [
      {
        "key": "material_key",
        "name": "资料名称",
        "description": "资料说明",
        "fileType": "image",
        "required": true,
        "minCount": 1,
        "maxCount": 5,
        "acceptTypes": ["image/jpeg", "image/png"]
      }
    ]
  }
]
```

**字段说明**：

#### 任务模板对象

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 任务ID，使用UUID |
| key | string | 是 | 任务唯一标识，如：site_survey |
| name | string | 是 | 任务名称，如：现场勘察 |
| description | string | 否 | 任务描述 |
| defaultWeight | int | 否 | 默认权重，0-100 |
| materialRequirements | array | 是 | 资料需求数组 |

#### 资料需求对象

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| key | string | 是 | 资料类型唯一标识 |
| name | string | 是 | 资料名称，如：安装前照片 |
| description | string | 否 | 资料说明 |
| fileType | string | 是 | 文件类型：image/video/document/spreadsheet/cad/other |
| required | boolean | 是 | 是否必填 |
| minCount | int | 否 | 最少数量 |
| maxCount | int | 否 | 最多数量 |
| acceptTypes | array | 否 | 接受的MIME类型 |

## 数据字典

### 枚举类型定义

#### 1. permission.type (权限类型)

| 值 | 说明 |
|----|------|
| menu | 菜单权限，控制页面访问 |
| button | 按钮权限，控制操作按钮 |
| api | 接口权限，控制API访问 |

#### 2. stage.progress_mode (推进方式)

| 值 | 说明 |
|----|------|
| by_task | 按任务推进，阶段进度 = 已完成任务数 / 总任务数 |
| by_device | 按设备推进，阶段进度 = 已完成设备数 / 总设备数 |

#### 3. material_requirement.file_type (文件类型)

| 值 | 说明 |
|----|------|
| image | 图片文件：JPG、PNG、GIF |
| video | 视频文件：MP4、AVI、MOV |
| document | 文档文件：PDF、Word、PPT |
| spreadsheet | 表格文件：Excel、CSV |
| cad | CAD文件：DWG、DXF |
| other | 其他文件 |

### A. MyBatis-Plus JSON类型处理器配置

**FieldTypeHandler.java**
```java
@MappedTypes(JdbcType.VARCHAR)
public class JsonTypeHandler extends BaseTypeHandler<Object> {
    private static final ObjectMapper objectMapper = new ObjectMapper();

    @Override
    public void setNonNullParameter(PreparedStatement ps, int i, Object parameter, JdbcType jdbcType) throws SQLException {
        ps.setString(i, JSON.toJSONString(parameter));
    }

    @Override
    public Object getNullableResult(ResultSet rs, String columnName) throws SQLException {
        String json = rs.getString(columnName);
        return parseJson(json);
    }

    // 其他方法...
}
```

**实体类使用**
```java
@TableField(typeHandler = JsonTypeHandler.class)
private List<StageTaskTemplate> taskTemplates;
```

### B. 性能优化建议

1. **JSON字段查询**：
   - JSON字段不建索引
   - 避免在WHERE子句中直接查询JSON字段
   - 如需查询，考虑使用Generated Column存储关键字段

2. **树形结构查询**：
   - 权限树使用递归CTE查询
   - 缓存完整的权限树到Redis

3. **排序优化**：
   -工序和阶段按 sort_order 排序
   - 批量更新排序时使用事务
