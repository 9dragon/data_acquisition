## 1. 项目概述

### 1.1 项目背景

本项目为工业数据采集项目的内部管理系统，用于管理数采实施过程中的项目、设备、进度、问题和文档。已完成需求规格说明书（V1.2）和前端原型设计。

### 1.2 已完成工作

| 项目 | 状态 | 说明 |
|------|------|------|
| 需求规格说明书 | 已完成 | 1455行，13个核心实体，20个页面级功能 |
| 前端原型 | 已完成 | React原型（参考），将重写为Vue3 |
| 概要设计 | 已完成 | 技术选型完成，架构设计完成 |
| 前后端框架搭建 | 已完成 | Spring Boot 3.2 + Vue3 3.4项目框架已搭建 |
| 数据库设计 | 未开始 | 需从零开始 |

### 1.3 关键技术挑战

1. **复杂进度计算** - 双层推进方式（按任务/按设备），多层级进度聚合
2. **三级联动机制** - 项目 → 工序 → 设备类型
3. **任务依赖引擎** - FS/SS/FF/SF四种依赖关系
4. **细粒度权限控制** - RBAC + 数据级权限
5. **大文件上传** - 文档100MB、图片10MB、视频50MB

### 1.4 功能优先级分布

| 优先级 | 功能数量 | 说明 |
|--------|----------|------|
| P0 | 8个 | 核心功能，必须首批实现 |
| P1 | 8个 | 重要功能，第二批实现 |
| P2 | 4个 | 增强功能，第三批实现 |

## 2. 第一阶段：概要设计

### 2.1 技术选型决策

#### 2.1.1 后端技术栈：Java Spring Boot

**推荐理由**：
- 企业级应用首选，生态成熟，团队技能储备丰富
- 适合复杂业务逻辑和长期维护
- MyBatis-Plus提供强大的ORM支持
- Spring Security提供完善的权限控制
- 丰富的中间件支持（Redis、RabbitMQ、XXL-Job）

**技术栈组合**：
```
后端框架：Spring Boot 3.2
ORM：MyBatis-Plus 3.5
数据库：MySQL 8.0+
缓存：Redis 7.0+
任务调度：XXL-Job
文件存储：MinIO
消息队列：RabbitMQ 3.12+
认证：Spring Security + JWT
监控：Actuator + Prometheus
API文档：Knife4j (Swagger增强版)
```

#### 2.1.2 前端技术栈：Vue3

**推荐理由**：
- 学习曲线平缓，上手容易
- Element Plus组件库完善，UI效果优秀
- Pinia状态管理简洁高效
- Vue Router 4路由功能强大
- AI代码生成友好，开发效率高

**技术栈组合**：
```
前端框架：Vue 3.4 + TypeScript 5.3
状态管理：Pinia 2.1
UI组件：Element Plus 2.5
路由：Vue Router 4.2
构建：Vite 5.0
图表：ECharts 5.4
工具库：VueUse 10.7
```

#### 2.1.3 数据库选型：MySQL 8.0

**推荐理由**：
- 国内使用最广泛（>90%市场占有率）
- 运维成熟，人才储备丰富
- 云服务支持最好（阿里云RDS、腾讯云等）
- JSON类型足够支持半结构化数据
- 全文搜索通过ngram插件支持中文

### 2.3 重难点功能设计

#### 2.3.1 复杂进度计算架构

**设计要点**：
- 统一的进度计算引擎，支持多种计算模式
- 事件驱动架构，进度变更自动触发级联更新
- Redis缓存热点项目进度数据
- 异步处理大规模进度重新计算

**计算层级**：
```
任务进度 → 设备进度 → 阶段进度 → 项目进度
```

#### 2.3.2 工序联动机制

**设计要点**：
- 后端提供统一的联动查询接口
- 前端使用状态管理库管理联动状态
- 三级联动：项目 → 工序 → 设备类型
- 切换项目时自动清空已选工序

#### 2.3.3 任务依赖引擎

**设计要点**：
- 使用有向无环图（DAG）建模任务依赖
- 支持四种依赖关系：FS/SS/FF/SF
- 前置任务未完成时，后续任务不能开始
- 循环依赖检测

#### 2.3.4 权限控制架构

**设计要点**：
- RBAC模型：基于角色的访问控制
- 数据级权限：项目级、设备级、文档级权限继承
- 后端统一权限验证拦截器
- 前端路由级和组件级权限控制

#### 2.3.5 大文件上传方案

**设计要点**：
- 分片上传技术（5MB每片）
- 断点续传支持
- 异步上传和进度反馈
- MinIO/OSS对象存储

#### 3.2.3 错误码定义

```json
{
  "code": 1001,
  "message": "用户名或密码错误",
  "details": {}
}
```

### 3.3 前端对接设计

#### 3.3.1 API调用封装

```typescript
// services/api.ts
import axios from 'axios';

const apiClient = axios.create({
  baseURL: '/api/v1',
  timeout: 10000,
});

// 请求拦截器
apiClient.interceptors.request.use((config) => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// 响应拦截器
apiClient.interceptors.response.use(
  (response) => response.data,
  (error) => {
    if (error.response?.status === 401) {
      // 跳转登录页
    }
    return Promise.reject(error);
  }
);
```
